# Escape 60 — audio credits and licenses

All audio was downloaded from OpenGameArt.org under the license shown. Files were **excerpted, faded,
loudness-normalised, down-mixed (SFX) and re-encoded** for the web by `scripts/process-audio.py`.
No audio from GTA or any other commercial game is used. CC-BY tracks require this attribution; it is
also shown in the in-game settings («سازندگان صدا»).

## Synthesised in-game (original)
Explosion, nitro burst and hiss, repair (impact wrench + chime), exhaust backfire and wind noise are generated at runtime with the Web Audio API (`web/src/audio.js`); no recorded asset is used for them.
