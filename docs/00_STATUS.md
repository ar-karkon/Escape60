# وضعیت واقعی پروژه — 2026-11-19

## Implemented (tested via Node)
- ریپوی عمومی `ar-karkon/Escape60` ساخته شده است.
- موتور بازی ۶۰ ثانیه‌ای، فیزیک آرکید، پلیس، ترافیک، برخورد، امتیاز، چالش روزانه و لینک دوستان پیاده‌سازی شده‌اند.
- رابط مرورگر (WebGL2 / Three.js) و کنترل لمسی/کیبورد، منو، توقف، خروج، شروع مجدد و نتیجه پیاده شده است.
- بک‌اند Node.js با ذخیره امتیازها در فایل و اعتبارسنجی بازپخش ورودی ساخته شده است.
- اسکریپت تست، build و CI ساخته شده‌اند. نتایج اجرای تست در محیط توسعه باید جداگانه ثبت شود.

## Deployed (2026-11-19)
- بازی روی Edge Computing آروان منتشر شد: https://escape60.lavanai2525-3qem7.arvanedge.ir — فایل‌های استاتیک از صندوقچه‌ی عمومی `escape60-game` و API داخل همان Edge.

- رویداد ویژه‌ی AI، بی‌سیم پلیس و مربی هوشمند پیاده شده‌اند؛ با تنظیم متغیرهای `S3_*` و `AI_API_KEY` در Edge جدول دائمی و AIaaS فعال می‌شوند.
