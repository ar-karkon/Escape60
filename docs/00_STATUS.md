# وضعیت واقعی پروژه — 2026-11-20 (نسخه ۳.۵.۱ — منتشرشده روی آروان)

- نسخه‌ی ۳.۵.۱ «بررسی یکپارچگی»: همه‌ی قابلیت‌های ۳.۳ (فلش‌ها و دوربین تعقیب، شروع تصادفی، نمای هوایی، ده محله) با ۳.۴ (داور لبه، رقیب شبح، کارت‌ها) و ۳.۵ (گزارش شهر، بی‌سیم، سرمکانیک) کنار هم تست شد. تنها تداخل پیدا‌شده رفع شد: در حالت عمودی، هشدار «پلیس پشت سرته» و فلش‌های پایین دیگر با خط بی‌سیم روی هم نمی‌افتند. شبیه‌ساز SIM 2.2.0 است و API پس از اصلاح زمان پاسخ Edge به 4.1.2 رسید. راهنمای قدم‌به‌قدم دیپلوی، چک‌لیست بعد از دیپلوی و برگشت به نسخه‌ی قبل در [22_DEPLOYMENT.md](22_DEPLOYMENT.md) است.

- نسخه‌ی ۳.۵ «مدیر شهر»: هر روز یک مدل روی AIaaS آروان گزارش شهر را می‌نویسد — سه قرارداد با جایزه و تاکتیک‌های پلیس که شبیه‌ساز با آن‌ها بازی می‌کند (برای همه یکسان و قفل‌شده) — به‌علاوه‌ی بی‌سیم پلیس دوزبانه، تماس مرکز برای هر رانندگی و گزارش سرمکانیک بعد از هر رانندگی تأییدشده. داخل بازی اسمی از هوش مصنوعی نیست؛ «پشت صحنه‌ی بازی» در بخش اعتبارها به `docs/TECHNOLOGY.fa.md` لینک می‌دهد. ۳۱ تست (با درگاه AIaaS شبیه‌سازی‌شده) و تست مرورگر روی فایل Edge ساخته‌شده پاس شد؛ پرامپت‌ها هنوز روی مدل زنده اجرا نشده‌اند.
- نسخه‌ی ۳.۴ «داور لبه»: لبه هر ۵ ثانیه ورودی‌های رانندگی را حین بازی دوباره شبیه‌سازی می‌کند (امتیاز معتبر + رتبه‌ی جهانی زنده)، سرعت غیرواقعی را رد می‌کند، رقیب شبح را از رانندگی‌های تأییدشده انتخاب می‌کند، کارت اشتراک PNG و پیش‌نمایش لینک را روی لبه می‌سازد، فایل‌ها را با Brotli می‌فرستد و داشبورد `/edge` آمار زنده و آزمایشگاه تقلب دارد. ۲۴ تست Node و تست مرورگر روی همان فایل Edge ساخته‌شده (`npm run edge:local`) پاس شد.
- نسخه‌ی ۳.۳: پلیس‌ها خیلی بهتر دیده می‌شوند (فلش‌های دور ماشین با فاصله، نور آژیر از لبه‌ی صفحه، نشانگر روی پلیس‌های دیده‌شده، هشدار «پلیس پشت سرته»، دوربینی که وقتی پلیس پشتت است عقب و بالا می‌رود تا هر دو دیده شوید، و نمای سینمایی آهسته وقتی یک پلیس برای اولین بار قفل می‌کند)؛ هر دور از یک نقطه‌ی تصادفی شهر شروع می‌شود (SIM 2.1.0، روی سرور هم بازپخش می‌شود) با یک نمای هوایی که از بالای شهر تا پشت ماشین شیرجه می‌زند؛ شهر به ده محله با معماری، کف‌پوش، چراغ، درخت، تابلو و نشانه‌های خودش تقسیم شد.
- نسخه‌ی ۳.۱: هویت قبلی خلیج غروب (لوگوی پیکسلی، فونت روئین و Jersey 10، آیکون‌ها و قاب‌های پیکسلی، آسمان سرخابی با خورشید راه‌راه و ابرهای پیکسلی) با همه‌ی قابلیت‌های نسخه‌ی ۳ ترکیب شد.

## پیاده‌سازی و آزمایش‌شده
- بازسازی کامل به سمت یک بازی ریسینگ خیابانی کلاس جهانی: نقشه‌ی جدید با خیابان‌های خمیده، فیزیک دریفت، ترمز، ترمزدستی و نیترو، ۱۴ ماشین، ۵ پیت‌استاپ با ۳ بار تعمیر، دود و آتش هنگام آسیب، انفجار، ادامه‌ی بازی بعد از ۶۰ ثانیه با جشن و امتیاز، افکت‌های قابل انتخاب، افکت‌های دوربین و بلور.
- تست‌های Node (۳۱ تست): قطعیت شبیه‌سازی، شروع از ۵۰ نقطه، بازپخش کامل و تکه‌ای، داور زنده و اثبات سرعت، رد امتیاز جعلی و ماشین یا نقطه‌ی شروع اشتباه، قراردادها و تاکتیک‌های روز، درگاه AIaaS شبیه‌سازی‌شده، پیت‌استاپ، نیترو، دریفت.
- تست مرورگر (`npm run test:browser`): یک دور کامل خودکار که حین بازی و در پایان روی سرور تأیید می‌شود، هم روی `npm start` و هم روی همان فایل Edge ساخته‌شده (`npm run edge:local`) پاس شد.
- اسکرین‌شات‌های واقعی مرورگر در `docs/screenshots/` (موبایل عمودی، دسکتاپ، شب، فارسی).
- قابلیت‌های هوش مصنوعی و اشاره به آروان از خود بازی حذف شدند.

## هنوز تأیید نشده
- FPS روی گوشی واقعی، میکس صدا با گوش، Safari.
- پرامپت‌های AIaaS روی مدل زنده (فقط با درگاه شبیه‌سازی‌شده تست شده‌اند).
- انتشار نسخه‌ی ۳.۵.۱ روی آدرس زنده: هنوز انجام نشده (آدرس زنده هنوز نسخه‌ی ۲.۳ است). نشست ابری به سرورهای آروان دسترسی ندارد؛ از کامپیوتر خودتان طبق [22_DEPLOYMENT.md](22_DEPLOYMENT.md) دیپلوی کنید: `git pull` ← `npm ci` ← `npm run check` ← پشتیبان از کد Edge فعلی ← `npm run deploy` ← چسباندن کد Edge در پنل ← چک‌لیست بعد از دیپلوی.
