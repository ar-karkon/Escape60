# Quality assurance / playtesting

## Manual core flows
- First click starts without sign-in; controls understood without text.
- Run lasts <= 60s; correct timer at 60Hz and 30Hz.
- Collision deterministic/understandable; no invisible hits.
- Retry always resets seed/status/AI/audio; no stale score.
- Background tab/phone sleep behavior documented.
- Result share correctly includes URL, no fake rank.
- Failed internet: practice still works and online features clearly unavailable.

## Device matrix (to test, not claims)
- Android Chrome low/mid phone, iOS Safari (recent/older), desktop Chrome/Firefox.
- Touch drag and screen rotation; RTL copy; low bandwidth; cache cold/warm.
- Reduced motion/sound; high-density screen; audio permission path.

## Suggested gates
- P0 crash count = 0 for 20 consecutive manual end-to-end runs.
- At least 5 novice testers; note time to first play and voluntary retry.
- Input latency targeted below 100ms at typical frame rates (measure).
- LCP first interaction/asset size measured and budget reviewed.
- Edge API rejects tampered or reused run ids; leaderboard remains correct under simultaneous submissions.

## Test artifacts
`tests/reports/YYYY-MM-DD.md` with device/build/seed/steps/expected/actual/screenshots. Never copy personal data into public issues.
