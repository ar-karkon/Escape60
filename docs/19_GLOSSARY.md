# Glossary

- **Vertical Slice:** thin but playable sample containing the fundamental experience, not a polished full game.
- **Core Loop:** sequence play → result → replay/share.
- **Seed:** repeatable random value used for deterministic challenge configuration.
- **Director:** rules controlling encounter escalation over the 60-second run.
- **Edge:** computation close to end users; runtime capabilities depend on provider.
- **Authoritative validation:** server checks sufficient to trust competitive score; a signed token alone is not authoritative gameplay verification.
- **Unique player:** competition-defined measurement; not equivalent to browser request/session; current methodology pending rules.
- **PROPOSED:** not approved or implemented.
- **CONFIRMED:** agreed project direction, not necessarily coded.
