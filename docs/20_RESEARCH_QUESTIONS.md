# Open questions and how to resolve them

## Contest
- Full primary rulebook: rating criteria, player uniqueness, data collection, eligibility, multiple game submissions, actual judge requirements.
- Is official submission path still functional? Screenshot/receipt.

## Engine / fun
- Is 2.5D better than top-down or full 3D for first 2 seconds of comprehension?
- Portrait or landscape; which is easier for viral links?
- Two-button controls vs drag steering; novice test.
- Full completion vs survival-only score; how rare should 60s survival be?

## Technology
- Arvan Edge JavaScript runtime APIs, CPU/memory limits, available storage, costs, custom domain, test environment, CORS, request limits.
- Can inputs be replay-validated cheaply and fairly?
- WebAudio/autoplay constraints and compression strategy for Safari.

## Brand/legal
- Working-name trademark/domain clearance, asset license, repo licensing decision.

## Growth
- Identify 10 real small creators for test outreach; no spam.
- Which hook improves `landing→start`, without false claims?
