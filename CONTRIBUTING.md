# 🤝 Contributing to Escape 60

Thank you for helping improve Sunset Bay!

The repository is public and **source-available**, but currently has **no general open-source reuse licence**. Ask the owner for written permission before copying project code or artwork into another project.

## Before opening a PR

1. Look for an existing issue and explain the scope of your change.
2. Read `AGENTS.md`, `docs/00_STATUS.md` and the relevant design/architecture documentation.
3. Keep PRs focused. Include reproduction steps or real in-game screenshots where applicable.
4. Keep the simulation and Edge authoritative replay compatible; never trust browser-supplied score values.
5. Run `npm install`, `npm run check` and `npm run build`. Test gameplay on a real browser when relevant.
6. Keep every UI string in **Persian and English**. Avoid unlicensed assets, ripped commercial game media and committed secrets.

Recommended branches: `feat/...`, `fix/...`, `docs/...`.

We especially welcome performance testing on real phones, accessibility work, QA, translation improvements and responsible game-balancing feedback.

**Security:** Please contact the owner privately through their GitHub profile instead of publicly disclosing active exploits or credentials.
