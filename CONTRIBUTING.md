# Contributing

Current phase is pre-production. Discuss large gameplay/design changes using an issue and record outcomes in `docs/13_DECISIONS.md`. For code submissions in the future: keep PR focused, provide reproducible tests/manual reproduction, label unverified claims, do not introduce unlicensed assets or secrets. A public repository does not yet carry an open-source license; request written permission before reuse or redistribution.

Suggested branches: `docs/...`, `feat/...`, `fix/...`. Suggested commits: `docs:`, `feat:`, `fix:`, `test:`, `chore:`.
